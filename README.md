# 🏠 AI Real Estate Assistant

AI-powered real estate search platform with conversational interface.

## 🎯 About This Project

This is my **final year project** for college. I forked an existing open-source project and customized it to understand how AI + SaaS applications work in real estate.

**What I did:**
- ✅ Set up the complete development environment
- ✅ Configured Docker containers for demo mode
- ✅ Tested all features (property search, AI chat, analytics)
- ✅ Made customizations to the UI and features
- ✅ Learned about FastAPI, Next.js, and AI integration

## 🚀 Features

- 🔍 Natural language property search ("2-bedroom apartment in Kraków under 500k")
- 🤖 AI-powered chat assistant
- 📊 Financial tools (mortgage calculator, ROI analysis)
- 🗺️ Interactive property maps
- 🌍 Multi-language support (9 languages)

## 🛠️ Tech Stack

- **Frontend:** Next.js 16, React 19, TypeScript
- **Backend:** FastAPI (Python 3.12+)
- **Database:** PostgreSQL, ChromaDB (vector search)
- **AI:** Multiple LLM providers (OpenAI, Anthropic, Google, etc.)
- **Deployment:** Docker, Render

## 📦 Installation

```bash
# Clone the repository
git clone [https://github.com/PriyaMittal-0402/ai-real-estate-assistant.git](https://github.com/PriyaMittal-0402/ai-real-estate-assistant.git)
cd ai-real-estate-assistant

# Start demo mode (no API keys needed)
.\scripts\demo\01-launch-docker.ps1
.\scripts\demo\02-generate-data.ps1

# Access at:
# Frontend: http://localhost:3082
# Backend: http://localhost:8082/docs
```
